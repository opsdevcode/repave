How import stays safe
  • Files move with git mv, so history follows them.
  • The layout change lands as one commit with zero content edits; the scaffold lands as a second commit you can review on its own.
  • Every moved file is SHA-256 checked before and after the move, and the move commit is added to .git-blame-ignore-revs.
  • Your existing source files always win — import never grafts generated resource code on top of code you already have.
  • Two files competing for the same destination fail the plan instead of one silently overwriting the other.

CLI equivalent: repave import https://github.com/acme/legacy-vpc --open-pr
