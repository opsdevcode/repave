# v3 brand track

v2 Converge remains canonical on `main` until v3 merge-back. This page is the v3 identity
track on `next/v3`. Decision record: [ADR 009](../adr/009-v3-product-identity.md).

Do not treat [README.md](README.md) Converge rules as the v3 default once the new mark
lands. Until the ADR 009 display-name cell is filled, **do not** add production SVG/PNG
marks here. Other v3 work on `next/v3` uses interim Converge chrome.

## Dual-track

| Track | Branch | Source of truth |
| --- | --- | --- |
| Converge (v2) | `main` | [README.md](README.md), `assets/` |
| v3 identity | `next/v3` | ADR 009 + this file + new assets (after the display name is recorded) |

White-label (`portal.logo_url`, `portal.accent_color`) stays a tenant overlay on both
lines. It is not the product identity.

## Asset checklist (after the display name is in ADR 009)

1. Edit SVG under `assets/svg/` first (new v3 filenames; do not overwrite Converge
   sources until merge-back).
2. Regenerate PNG, favicon, and social exports.
3. Copy into `engine/src/repave_engine/static/brand/` for the portal.
4. Update portal tokens (accent only; semantic green / orange / rose unchanged; family
   drawer colors independent of brand gold).
5. Recapture README screenshots **once** against the v3 shell.

Do not crop the Converge concept-board PNG as production art. Do not use brand accent
for success / warning / error.
