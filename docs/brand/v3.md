# v3 brand track

v2 Converge remains canonical on `main` until v3 merge-back. This page is the v3 identity
track on `next/v3`. Decision record: [ADR 009](../adr/009-v3-product-identity.md).

Display name: **repave**. Mark: isometric platform slabs + golden path. Tagline: *The
intelligent platform layer*. Do not treat Converge as the v3 default. Do not crop the
concept-board PNG as production art.

Concept board: [reference/repave-v3-brand-direction.png](reference/repave-v3-brand-direction.png).
Regenerate SVG with `python3 docs/brand/render_mark.py`, then PNG via `rsvg-convert`.

## Dual-track

| Track | Branch | Source of truth |
| --- | --- | --- |
| Converge (v2) | `main` | [README.md](README.md), `assets/` (on `main`) |
| v3 identity | `next/v3` | ADR 009 + this file + `assets/` on this branch |

White-label (`portal.logo_url`, `portal.accent_color`) stays a tenant overlay on both
lines. It is not the product identity.

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| Deep Navy | `#0F172A` | Primary background / foundation |
| Slate | `#64748B` | Secondary surfaces / text |
| Cool Gray | `#94A3B8` | Secondary UI |
| Light Gray | `#E2E8F0` | Light surfaces / text |
| Amber / Gold | `#F59E0B` | Repave / golden path / primary action |

Semantic green / orange / rose stay independent of brand amber. Family drawer colors
stay independent of brand gold.

## Asset checklist

1. Edit SVG via `render_mark.py` (or by hand under `assets/svg/`).
2. Regenerate PNG, favicon, and social exports (`rsvg-convert`).
3. Copy into `engine/src/repave_engine/static/brand/` for the portal.
4. Portal default mark is `repave-mark-dark.svg` (night-ops shell).
5. README screenshots recaptured against the v3 shell (#648). Recapture again
   after the catalog hero and public landing land.
6. Keep the root README on the compact **PNG** lockups. Do not point GitHub
   markdown at SVG wordmarks that still use `<text>`.

Do not use brand accent for success / warning / error.
